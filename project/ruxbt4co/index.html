教师工作量管理系统

约 1448 字大约 5 分钟

2026-02-27

这个系统说白了就是帮学校统计教师的工作量。

一个老师一学期下来要记的东西很杂，上了多少课、带了几个班、发了什么论文、有没有指导学生、当没当班主任。以前这些全靠手工填表，再拿 Excel 汇总，一到学期末统计就乱成一团，谁的记录漏了、谁的数字对不上，得一个一个打电话问。做这个系统，就是把这些申报、审核、统计的活挪到线上。

我在里面负责前端，Vue3 加 Element Plus，后端 SpringBoot，我主要做页面和对接接口。

工作台是老师进来第一眼看到的东西，总课时、已通过的申报、待审核、被驳回的记录，四个数字摆在最上面，下面是最近的申报动态。这个页面的用处是让人一进来就知道自己这个学期干得怎么样、有几条还卡在审核里：

表单比功能难写

选 Vue3 没什么惊天动地的理由，就是新项目不想再写 Vue2 那套 options API。组合式 API 能把一个功能的逻辑聚到一块，不用像以前那样 data 翻一遍、methods 翻一遍、computed 再翻一遍，写多了确实舒服。Element Plus 就是 ElementUI 的 Vue3 版，后台要用的那些组件，表格、表单、弹窗、下拉框、日期选择，基本都给备齐了，省得自己手搓样式。

真做起来才发现，后台系统最耗时间的不是「功能」，是表单。

申报那个页面字段一大堆，每个字段的校验规则都得一条条配。类型必须选，数量必须是数字还得大于零，学期不能空着。Element Plus 的 el-form 自带 rules，看着挺方便，但字段一多就开始冒破事——prop 和 rules 里的名字对不上、校验死活不触发、明明填了还报「请输入」。这种错不报错、只是不生效，只能一行行对。

<el-form :model="form" :rules="rules" ref="formRef">
  <el-form-item label="工作量类型" prop="type">
    <el-select v-model="form.type">
      <el-option label="教学" value="teaching" />
      <el-option label="科研" value="research" />
      <el-option label="其他" value="other" />
    </el-select>
  </el-form-item>
  <el-form-item label="数量" prop="amount">
    <el-input v-model.number="form.amount" />
  </el-form-item>
</el-form>

列表页反而最省心，el-table 配个分页、加几个筛选条件就完事，组件都是现成的，一下午能出三四个页面。我做的时候有种很奇怪的感觉，费劲的地方不显眼，显眼的地方不费劲。

三个不致命但很烦的问题

ref 和 reactive 我一开始是真没分清。ref 包了对象忘了写 .value，改半天数据页面纹丝不动，还以为是自己逻辑写错了；reactive 的对象一解构，响应式直接丢了，页面永远显示第一次的值。后来硬记成一句话，基本类型用 ref，对象用 reactive，别混着来。听上去很教条，但省了我不少时间。

跨域是老朋友了。前端 5173、后端 8080，第一次联调浏览器就报 CORS，控制台红一片。开发环境配个 proxy 转发就好，但我第一次碰见的时候是真懵，还以为是接口地址写错了，把 controller 翻了三遍。

token 过期这个坑是后来才补的。登录拿的 token 有有效期，过期了接口返回 401，如果不在响应拦截器里统一处理，用户正填着表单突然就跳成「未登录」，填的东西全没了。后来加了个拦截，401 就清掉本地 token、跳回登录页。

service.interceptors.response.use(
  res => res,
  err => {
    if (err.response?.status === 401) {
      localStorage.removeItem('token')
      router.push('/login')
    }
    return Promise.reject(err)
  }
)

做完再看

后台系统的门槛确实不高，套组件就能出活，这也是我做完之后最直接的感受，甚至有点失落，觉得这活好像没什么技术含量。

但响应式、组件通信、拦截器这些看不见的东西，不自己踩一遍是吃不透的。前端这活，看着是画页面，功夫全在看不见的地方——同一个页面，会写的人两天写完还能改，不会写的人两周写完自己都不敢动。

要说最不满意的地方，是这套界面自始至终没给真人用过。我做的时候全靠自己想象一个老师会怎么点，等真有人用，估计第一件事就是抱怨申报页字段太多。
