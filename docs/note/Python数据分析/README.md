## 一、什么是数据分析？

刚接触这个词的时候，我总觉得它特别高大上，好像一定要会机器学习、要懂高数才行。学了一阵子才发现，**数据分析说白了就是一句话：把一堆乱糟糟的数据，整理干净、算一算、画成图，最后得出一个能指导行动的结论。**

比如手里有一张表格，记录了一个水果店一个月的销售流水（几万行）。老板想知道"哪个水果卖得最好""周几生意最差"，靠眼睛一行行看是不现实的，这时候就用代码来处理。整个过程可以拆成下面几个环节：

```text
提出问题  →  拿到数据  →  清洗数据  →  分析数据  →  得出结论/画图展示
```

所以数据分析不是数学题，更像一个"用代码把数据变成答案"的手艺活。

## 二、为什么用 Python 做数据分析？

做数据分析的工具其实不少，Excel 也能做。但数据一多（几万行、几十万行），或者操作很复杂，Excel 就卡了。Python 的好处主要有这几点：

1. **免费**，不用装盗版软件。
2. **语法相对好读**，对小白友好。
3. **库特别全**——处理表格、算数、画图，每个环节都有现成的库帮你干，你只要学会"调用"就行。

这里说的"库"，可以先理解成**别人已经写好的一堆工具函数的合集**，你用 `import` 把它引进来，就能直接用了，不用自己从头写。

## 三、环境准备（先能跑起来）

第一步，装 Python。去官网 [python.org](https://www.python.org/) 下载安装即可，安装时记得勾选 `Add Python to PATH`。

第二步，装下面这三个库。打开命令行（Win 上是 CMD 或 PowerShell，Mac 上是终端），输入：

```bash
pip install numpy pandas matplotlib
```

`pip` 是 Python 自带的包管理工具，作用就是帮你下载安装这些库。安装完，就可以在代码里 `import` 它们了。

> 补充：如果你嫌命令行麻烦，也可以直接装 **Anaconda**，它是一个打包好的大环境，Python 和常用库一次装齐，还自带一个很好用的 Jupyter Notebook（可以一行一行运行代码、随时看结果），特别适合新手边学边试。

## 四、数据分析的三大核心库

这三个库分工很明确，先记住它们各自"管什么"，后面就不会乱：

| 库 | 中文叫法 | 干什么用 |
|----|---------|---------|
| NumPy | 数值计算库 | 处理"数组"和数值运算，是底层基础 |
| Pandas | 表格处理库 | 处理像 Excel 那样的二维表格，**用得最多、最核心** |
| Matplotlib | 画图库 | 把数据画成折线图、柱状图、饼图 |

我们平时写代码，习惯给它们起个短别名，这样打字少：

```python
import numpy as np        # 起别名 np
import pandas as pd       # 起别名 pd
import matplotlib.pyplot as plt   # 画图模块起别名 plt
```

## 五、Pandas 的两个核心概念：Series 和 DataFrame

Pandas 是整个数据分析的核心，所以先把它的两个数据结构搞清楚。这两个词第一次见会有点懵，我用表格来类比：

- **Series（序列）**：就是一列数据，可以理解成"一列"。
- **DataFrame（数据框）**：就是一个完整的二维表格，由很多列（Series）拼起来，可以理解成"一整张 Excel 表"。

下面这张表就是一个 DataFrame：

| 姓名 | 年龄 | 城市 |
|------|------|------|
| 小明 | 20 | 广州 |
| 小红 | 22 | 深圳 |

其中"年龄"这一列单独拿出来，就是一个 Series。

用代码创建一个最简单的 DataFrame：

```python
import pandas as pd

data = {
    '姓名': ['小明', '小红', '小刚'],
    '年龄': [20, 22, 21],
    '城市': ['广州', '深圳', '珠海'],
}

df = pd.DataFrame(data)   # 把字典转成 DataFrame
print(df)
```

运行结果是：

```text
   姓名  年龄  城市
0  小明  20  广州
1  小红  22  深圳
2  小刚  21  珠海
```

最左边那列 `0 1 2` 是 Pandas 自动加的行号，叫**索引（index）**，先知道它存在就行。

## 六、读数据：把文件读进来

真实工作里，数据通常在一个文件里，常见的有 CSV 和 Excel 两种。

- **CSV**：纯文本表格，用逗号分隔，任何软件都能打开，最通用。
- **Excel**：就是我们熟悉的 `.xlsx` 文件。

读 CSV 用 `read_csv`，读 Excel 用 `read_excel`：

```python
import pandas as pd

# 读取同目录下的 sales.csv 文件
df = pd.read_csv('sales.csv')

# 如果是 Excel 就换成下面这行
# df = pd.read_excel('sales.xlsx')

# 看前 5 行，快速确认读没读对
print(df.head())
```

`head()` 就是"看头部几行"的意思，默认看 5 行。还有一个常用的 `info()`，能告诉你这个表有多少行、每列是什么类型：

```python
print(df.info())   # 看整体情况
```

## 七、数据清洗：把脏数据弄干净

刚拿到的数据，几乎没有"天生干净"的，总会遇到下面这些脏东西。这一节是数据分析里**最耗时间**的环节。

### 1. 缺失值（空着没填的格子）

空值在 Pandas 里统一用 `NaN` 表示（Not a Number，意思是"这里没有数"）。

```python
# 方法一：直接把有空值的行删掉
df = df.dropna()

# 方法二：把空值填上一个数（比如用 0 填，或填这一列的平均值）
df['销售额'] = df['销售额'].fillna(0)
```

新手注意：**删掉 `dropna()` 会返回一个新的表，不会改动原来的表**，所以要么像上面那样重新赋值给 `df`，要么加参数 `inplace=True`。

### 2. 重复值（一模一样的行出现了好几次）

```python
# 删除完全重复的行，只保留第一次出现的
df = df.drop_duplicates()
```

### 3. 类型不对（数字被当成了文字）

比如"销售额"这一列本来是数字，但因为里面混了 `"100元"` 这种带单位的文本，整列就被识别成了字符串。这时候要先清理再转换类型：

```python
# 把 '100元' 里的 '元' 去掉，再转成数字
df['销售额'] = df['销售额'].str.replace('元', '').astype(float)
```

## 八、分析数据：筛选、排序、分组

数据干净了，就可以开始"问数据问题"了。下面是三个最常用的操作。

### 1. 筛选（找出符合条件的数据）

```python
# 找出销售额大于 500 的所有行
df[df['销售额'] > 500]

# 多个条件用 & 连接（注意每个条件都要加括号）
df[(df['销售额'] > 500) & (df['城市'] == '广州')]
```

### 2. 排序

```python
# 按销售额从大到小排
df.sort_values('销售额', ascending=False)
```

`ascending=False` 表示降序（从大到小），不写默认是升序。

### 3. 分组统计

`groupby` 是"分组"的意思，配合 `sum()`、`mean()` 就能按某一列分组再算总数、算平均值：

```python
# 按"城市"分组，统计每个城市的销售额总和
df.groupby('城市')['销售额'].sum()

# 按"城市"分组，算每个城市的平均销售额
df.groupby('城市')['销售额'].mean()
```

## 九、画图：用 Matplotlib 可视化

数据算完了，光看数字不直观，画成图一眼就能看懂。最简单的就是直接对 DataFrame 调用 `plot()`：

```python
import matplotlib.pyplot as plt

# 按城市统计销售额，然后画柱状图
df.groupby('城市')['销售额'].sum().plot(kind='bar')

plt.title('各城市销售额')   # 标题
plt.show()                  # 显示出来
```

常用的 `kind`（图形类型）：

| kind 参数 | 图形 |
|-----------|------|
| `'line'` | 折线图（看趋势） |
| `'bar'` | 柱状图（比大小） |
| `'pie'` | 饼图（看占比） |
| `'hist'` | 直方图（看分布） |

如果中文显示成方框，是字体问题，加这一行即可：

```python
plt.rcParams['font.sans-serif'] = ['SimHei']  # 用黑体显示中文
```

## 十、一个完整的小实战：分析一个月的水果销量

把前面学的串起来，走一遍完整流程。假设我有一个 `fruits.csv`，内容是一个水果店一个月的销售流水，大致长这样：

```text
日期,水果,销量,单价
2026-03-01,苹果,30,6.5
2026-03-01,香蕉,20,4.0
2026-03-02,苹果,25,6.5
...
```

目标是回答三个问题：**哪种水果卖得最好？每天总销售额是多少？销售额的趋势如何？**

```python
import pandas as pd
import matplotlib.pyplot as plt

# 让中文能正常显示
plt.rcParams['font.sans-serif'] = ['SimHei']

# 1. 读数据
df = pd.read_csv('fruits.csv')

# 2. 清洗：检查有没有缺失值和重复值
df = df.dropna()            # 去掉空行
df = df.drop_duplicates()   # 去掉重复行

# 3. 算一个新列：每行的销售额 = 销量 × 单价
df['销售额'] = df['销量'] * df['单价']

# 4. 回答问题一：哪种水果卖得最好（按销量合计）
print(df.groupby('水果')['销量'].sum().sort_values(ascending=False))

# 5. 回答问题二：每天总销售额
daily = df.groupby('日期')['销售额'].sum()
print(daily)

# 6. 回答问题三：画每天销售额的折线图，看趋势
daily.plot(kind='line')
plt.title('每日销售额趋势')
plt.show()
```

跑完这段代码，三个问题就都有答案了。你会发现，数据分析的套路其实就这一套：**读 → 洗 → 算 → 画**，换成别的数据也一样。

## 十一、小白容易踩的坑（我自己踩过的）

1. **文件名/路径不对**：`read_csv('fruits.csv')` 里的文件必须和你的脚本在同一个文件夹，否则要写完整路径。报错 `FileNotFoundError` 就是没找到文件。

2. **编码报错**：读 CSV 遇到中文乱码或 `UnicodeDecodeError`，加个参数 `pd.read_csv('xxx.csv', encoding='utf-8')`，试试 `'gbk'` 或 `'gb18030'`（Windows 下中文文件常用）。

3. **忘了重新赋值**：`df.dropna()` 不会改原表，要写成 `df = df.dropna()`。

4. **用 `==` 判断 NaN**：判断一个值是不是空，不能用 `df['列'] == NaN`（永远判断不出来），要用 `df['列'].isna()`。

5. **中文乱码**：画图时中文变方框，记得加 `plt.rcParams['font.sans-serif'] = ['SimHei']`。

## 十二、下一步可以学什么

把上面这套跑熟练之后，可以继续往这几个方向走：

- 用 **Pandas 的 `merge`** 把两张表按某个字段合并（类似 Excel 的 VLOOKUP）。
- 用 **Matplotlib** 画更漂亮的图，或换成更现代的画图库 **seaborn**。
- 用 **`pandas` 处理真实数据集**，比如去 Kaggle 上找公开数据集练手。

数据分析是个"越做越熟"的活，套路是固定的，熟能生巧。先把读、洗、算、画这四步练扎实，后面学什么都快。
